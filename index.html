Termin.Scan
Setup-Anleitung
Alles kostenlos – du brauchst nur einen Google-Account.
🤖 Claude KI für beste Erkennung (~0,01€/Scan) + Google Kalender kostenlos. GitHub Pages für Vollbild-Installation kostenlos.
Neuer Anthropic-Account bekommt meist kostenloses Startguthaben.
1
🤖 Claude API Key holen ~0,01€/Scan
1. Gehe zu console.anthropic.com
2. Links: „API Keys" anklicken
3. „Create Key" → Key kopieren
4. Im ⚙ Einstellungen (oben rechts) einfügen
5. Speichern

💡 Kosten: ca. 0,01–0,02€ pro Scan.
Beim ersten Mal gibt es meist ein kostenloses Guthaben.
→ Anthropic Console öffnen
2
📅 Google Kalender einrichten (kostenlos)
Schritt A – Google Cloud Projekt:
1. Gehe zu console.cloud.google.com
2. „Neues Projekt" erstellen, z.B. TerminScan

Schritt B – Calendar API aktivieren:
1. → APIs & Dienste → Bibliothek
2. Suche „Google Calendar API" → Aktivieren

Schritt C – OAuth Client erstellen:
1. → APIs & Dienste → Anmeldedaten
2. „Anmeldedaten erstellen" → „OAuth 2.0-Client-ID"
3. Anwendungstyp: „Webanwendung"
4. Bei „Autorisierte JavaScript-Quellen" eintragen:
   → https://DEINNAME.github.io (für GitHub Pages)
   → http://localhost:8080 (für lokalen PC-Test)
5. Client-ID kopieren → ins ⚙ Einstellungen einfügen
→ Google Cloud öffnen
3
📲 Als App installieren (Vollbild) (kostenlos)
GitHub Pages – einmal einrichten, überall nutzen:
1. Konto erstellen auf github.com
2. „New repository" → Name: terminscan → Public → Create
3. „uploading an existing file" → alle Dateien aus dem ZIP hochladen
4. → Settings → Pages → Source: main → Save
5. Deine URL: https://DEINNAME.github.io/terminscan

App auf Android installieren:
→ URL in Chrome öffnen → Menü (⋮) → „Zum Startbildschirm hinzufügen"

Lokal am PC testen (ohne GitHub):
→ ZIP entpacken → im Ordner Terminal öffnen → eingeben:
python3 -m http.server 8080
→ Browser: http://localhost:8080
→ GitHub öffnen
⚠️ Wichtig für OAuth: Die URL die du bei „Autorisierte JavaScript-Quellen" einträgst muss exakt mit der URL übereinstimmen unter der die App läuft – also entweder deine GitHub Pages URL oder http://localhost:8080.
